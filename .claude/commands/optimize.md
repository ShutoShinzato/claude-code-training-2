---

Next.jsアプリケーションのパフォーマンスを最適化：

1. 現在のコードを分析
2. パフォーマンスのボトルネックを特定
3. 最適化提案（具体的な改善点を列挙）
4. 実装
5. Before/Afterを説明

以下の技術を活用してください：
- React Server Components
- 動的インポート（Dynamic Imports）
- 画像最適化（next/image）
- フォント最適化（next/font）
- コード分割
- メモ化（useMemo、useCallback、React.memo）
